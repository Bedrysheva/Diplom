# Работа с новым фукционалом

## 1. Планировщик

Для пользователей, с правами "Менеджер (работа по заявкам клиентов) на начальной странице откраывется обработка "График занятости: Календарь специалистов". По умолчанию, в ней отображаются данные документов "Обслуживание клиентов" на 7 дней, начиная с текущей даты. Период можно изменить произвольно. 

В поле планировщика по горизонтали располагается шкала времени, а по вертикали дни и сотрудники.
Если за указанный период нет не помеченных на удаление документов "Обслуживание клиентов" поле планировщика отображает зеленые строки. Если мышкой выделить область в одной строке, откроется документ "Обслуживание клиента" с уже запоненными "Датой работ" и "временем" значениями соответствующими выделенной области. Менеджеру нужно заполнить контрагента, организацию, договор и специалиста. После сохранения документа, его данные отобразятся в планировщике и появятся строки с именем специалиста. 
Выделяя временные области в белой строке специалиста можно создавать документы с уже заполенным  реквизитом "специалист".

В планировщике можно редактировать документы "Обслуживание клиента" перетаскивая временнные интервалы (синие прямоугольники с наименование контрагента) мышкой. Можно выделить сразу несколько интервалов и перенести работы одного специалиста другому, сдвинуть влево или вправо по времени, перенести на другой день. При этом будут открываться соответствующие документы "Обслуживание клиентов" с заполненными изменеными данными. Если документ сохранить, изменения отобразятся в планировщике, если закрыть - без сохранения изменения отменятся. Также в планировщике можно помечать на удаление документы "Обслуживание клиентов". Данные помеченных на удаление документов не отображаются в планировщке.

## 2. Обработка "Массовое создание актов об оказании услуг"

Доступна пользователям с группой доступа "Бухгалтер" и полные права. Находится в разделе *Обслуживание клиентов -> Сервис -> Массовое создание актов об оказании услуг*. Создает (или перезапоняет существующие) документы "Реализация товаров и услуг" за указанный месяц для действующих абонентских договоров.Документы сохраняется последним днем месяца, за который происходит выставление актов.

## 3. Расчет зарплаты

В документе "Начисление зарплаты" предусмотрено автозаполнение (кнопка "Заполнить") всеми сотрудниками предприятия и их ежемесячными начислениями. Информация о том, какие именно ежемечные виды начислений полагаются сотруднику хранится в табличной части  справочника "должности" (в разделе *"Расчет зарплаты" -> "Справочники" -> "Должности"*). Если в указанном периоде у сотрудника запланирован отпуск, будет добавлена строка с начислением "отпуск" и датами из документа "Годовые графики отпусков".

Табличную часть документа "Начисление фиксированной премии" можно автоматически заполнить всеми сотрудниками (Кннопка "Заполнить"), при этом можно указать размер фиксированной премии в поле "премия".

Табличную часть документа "Годовой график отпусков" можно заполнить автоматически всеми сотрудникми, нажав кнопку "Заполнить".
