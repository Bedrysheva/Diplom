# Инструкция по начальной настройке
## Настройка пользователей и их прав
Настройка прав пользователей осуществляется пользователем с активной ролью "Полные права" (в разделе *"Администирирование" -> "Настройки пользователей и прав" -> "Группы доступа" -> "Профили групп доступа"*) . Необходимо создать группы прав со следующими установленнми ролями:

1. Для специалистов:
* Базовые права БСП
* Специалист (работы по заявкам клиентов)
2. Для менеджеров, планирующих работы по заявкам абонентов:
* Базовые права БСП
* Менеджер (работа по заявкам клиентов)
3. Для бухгалтеров:
* Базовые права БСП
* Бухгалтер
4. Для кадровиков-расчетчиков
* Базовые права БСП
* Кадровик-расчетчик

Для редактирования или создания новых учетных записей пользователей перейдите в меню *«Настройки пользователей и прав» -> «Пользователи» -> «Пользователи»*. На вкладке "Основное" заполните обязательные поля «Полное имя» и «Имя (для входа)» - имя пользователя, которое будет отображаться в выпадающем списке при входе в базу данных. Проследите, чтобы был установлен флажок «Вход в программу разрешен». На вкладке «Права доступа» и поставьте флажок напротив ролей соответствующих должности пользователю.

## Настройка должностей и видов расчетов с сотрудниками
Информацию о должностях и начислениях заполняет пользователь с группой доступа "кадры" или "полные права".

В справочник "Виды графиков работ" нужно занести наименования используемых на предприятии рабочих графиков (пятидневка, шестидневка и т.п). Заполнить сами графики можно используя обработку "Заполнение графика" (в разделе *"Расчет зарплаты" -> "Сервис" -> "Заполнения графика"*). Для этого заполняем поля "График", "Период" (временной интевал за который нужно заполнить график), через запятую пишем номера выходных дней недели и нажнажимаем кнопку "Заполнить".

В базу уже внесены предопределенные виды начислений заработной платы и удержание НДФЛ. Для автоматического заполнения расчетных документов нужно заполнить реквизит "Способ расчета" у предопределенных элементов. Для этого переходим в форму списка основных начислений (*"Расчет зарплаты" -> "Справочники" -> "Виды расчета (основные)*" ) и для оклада и отпуска выбираем способ расчета "С учетом графика работ". В дополнительных начислениях (*"Расчет зарплаты" -> "Справочники" -> "Виды расчета (дополнительные)*) для начислений "Процент от работ" установливаем вид расчета "Процент от работ", а для "Фиксированная премия" - "Фиксированная сумма". И наконец для удержания налога НДФЛ переходим в раздел *"Расчет зарплаты" -> "Справочники" -> Виды удержаний* и выбираем соответствующий способ расчета для вида "НДФЛ".

В справочник "Должности" (в разделе *"Расчет зарплаты" -> "Справочники" -> "Должности"*) нужно ввести наименование должности и выбрать график по которому будет расчитывться оклад и отпуск. Также в табличной части "Ежемесячные начисления" выбираем виды регулярных начислений зарплаты. Так для должности "Специалист" табличная часть будут содержать две строки "Оклад" и "Процент от работ". Для "менеджера", "кадровика-расчетчика" и "бухгалтера" - только одну строку "оклад".

## Настройка информации о сотрудниках
Информацию о сотрудниках заполняет пользователь с группой доступа "кадры" или "полные права".

В справочнике "Физические лица" (в разделе *"Расчет зарплаты" -> "Справочники" -> "Физические лица"*) заполняется соответствие физического лица и его учетной записи в базе 1с. Реквизит "Краткое ФИО" будет отображаеться в документах и отчетах.

В регистре сведений "Условия оплат сотрудникам" (*раздел "Расчет зарплаты" -> "Справочники"*) для сотрудников заполняем должность, сумму ежемесячного оклада и процент от выполненных работ (для специалистов).

## Настройка сообщений в Telegrm
Настройка сообщений в Telegrm пользователей осуществляется пользователем с активной ролью "Полные права".

1. Для создания телеграм-бота заходим в телеграм и вводим в строку поиска "BotFather" - это конструктор телеграм-ботов. Нажимаем команду /start. Придет сообщение от BotFather с описанием команд. Выбираем /newbot для создания нового бота.
2. BotFather запросит у вас имя вашего бота, введите его. Имя бота может быть введено любым алфавитом, содержать знаки, цифры и эмодзи. Это имя будут видеть пользователи.
3. Далее BotFather запросит уникальное имя пользователя "username", с помощью которого можно найти бота в Телеграм. "Username" может быть написано только латиницей, цифрами и оканчиваться на "bot".
4. Если все введено корректно, BotFather пришлет токен - это строка из цифр и букв латинского алфавита.
Скопируйте строку токена. 
5. Зайдите в базу данных в раздел *Администрирование -> Сервис -> Настройка работы с абонентскими договорами* и вставьте токен бота в поле "токен". Запишите.
6. Создайте группу в Телеграмм. Добавьте только что созданного бота в группу и назначте ему адиминистративные права.
Отправте любое сообщение в группу. Скопируйте строку API запроса https://api.telegram.org/bot[ВашТокен]/getUpdates и вставьте в адресную строку браузера. Замените [ВашТокен] на строку вашего токена и выполните запрос.
Браузер отобразит JSON-код примерно такого вида:

```
   {
  "ok": true,
  "result": [
    {
      "update_id": 850767343,
      "message": {
        "message_id": 6,
        "from": {
          "id": 5146770208,
          "is_bot": false,
          "first_name": "Nadezhda",
          "last_name": "Bedrysheva",
          "language_code": "ru"
        },
        "chat": {
          "id": -1002738874908,
          "title": "[Наименование группы]",
          "type": "supergroup"
        },
        "date": 1751882228,
        "text": "test"
      }
    },
```    
   
7. Найдите в этотом коде строку содержащую id группы. В примере выше "id": -1002738874908. Скопируйте цифры вместе со знаком "-".

8. Зайдите в базу данных в раздел *Администрирование -> Сервис -> Настройка работы с абонентскими договорами* и вставте id телеграмм группы в поле "Идентификатор группы". Запишите.

## Настройка констант для документа Реализация товаров и услуг

Настройка констант осуществляется пользователем с активной ролью "Полные права". 
Зайдите в базу данных в раздел *Администрирование -> Сервис -> Настройка работы с абонентскими договорами*. Заполните константы "Работы специалиста" и "Абонентская плата" соответствующими ссылками на элементы справочника "Номенклатура". Проверьте, что "Вид номенклатуы" у этих элементов установлен "Услуги". Если таких элементов в базе еще нет, создайте их.

## Настройка договоров контарагентов

У элементов справочника "Договора контрагентов" появились новые реквизиты. Вводить новые договора, удалять и изменять могут пользователи с правами "Полные права", "Менеджер (работа по заявкам клиентов)" и "Бухгалтер" из раздела "*Обслуживание клиентов -> Справочники -> Договора контрагентов*".  Пользователи с ролью "Кадры" могут только редактировать существующие договора. Для договоров абонентского обслуживания "Вид договора" выбираем "Абонетское обслуживание". Заполнием время действия договора "действует с" и "по". Для расчета зарплаты и выставленной стоимости работ контрагенту указываем в договоре стоимость часа работ специалиста.
